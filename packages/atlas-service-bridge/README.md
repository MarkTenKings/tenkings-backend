# Scoped ATLAS grading bridge

Server-only protocol and transaction coordinator for the temporary extraction
adapter approved in `docs/atlas/COMPLETION.md`. It contains no login, admin proxy,
storage client, model SDK or alternative grading engine.

The staff app signs a 30-second request bound to destination, deployment, case,
session, assignment and evidence. The receiver independently checks current
database authority and resolves the preserved source owner and durable action.
The browser supplies neither a storage URL nor a worker request.

One durable execution claim precedes external work. The injected production port
calls the complete existing review service. Transaction hooks retain source CAS,
map/Memory/checkpoint validation and commit the ATLAS analysis, checklist reset,
operation and audit together. Uncertain outcomes remain held and cannot dispatch
again. A known preflight rejection fails without an execution claim.

The operator-owned policy names exactly ten existing specimens, an expiry,
maximum action count and nonzero operation/card/total budgets in micro-USD.
Every claim reserves the configured full worst-case allowance. Success does not
invent billing evidence or release reservations. Actual cost settlement needs a
separate operator and preserved evidence hash; overruns stop pilot admission.
Budget and grading policy have separate hashes, preserving valid analyses when
the budget changes. Execution is gated again at transaction commit.

Production grading policy derives from the compiled ATLAS rule, current detector
policy and admitted preparation identity. The last remains deliberately unset
pending operational worker/storage acceptance. This code activates no live run.

Fixture ports explicitly use synthetic measurements. They prove database
authority, concurrency, rollback and budget behavior, not optical quality or
real costs. Protocol tests use injected responses and no network. Build the
shared grading core, then run `node --test test/*.test.mjs`; the staff disposable
PostgreSQL harness owns integration fixtures and their migration evidence.
