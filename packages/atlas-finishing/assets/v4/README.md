# ATLAS V4 deterministic vector assets

The original Sports and Pokémon PRINT SVGs are byte-identical copies of the owner-supplied `ATLAS_V4_Print_Test_Package`. Its original dynamic generator and font binaries were not supplied. `vector-parts.json` extracts the original body/cut clip, logo, fingerprint template, foil tracks, brackets and gray details without reshaping them. The fingerprint is decorative template artwork, not a unique physical-card identifier. The original 10 numeral remains its custom outlined path. The original physical cut paths, including the 10.2 mm NFC hole, remain unchanged.

`provenance.json` pins every source and derived asset by SHA-256. Headline outlines match Montserrat Black (weight 900), recovered from the official Google Fonts Montserrat 9.000 variable font. Details match Roboto Condensed Bold (weight 700), official version 3.008. Each font URL is pinned to a repository commit and its downloaded bytes were independently compared with that pinned URL. Both OFL licenses are included. Fontkit 2.0.4 performs shaping with kerning disabled, matching the supplied generator's advances; there is no system-font lookup or fallback. Supplied headline widths differ by less than 0.003 mm because the old vectors quantize FreeType outlines. Tests cover the actual specimen metrics and its Wembanyama/Antetokounmpo attention cases.

`atlas-v4-outlined-label-v1` generates paths for authoritative names, confirmed metadata, grade, complete report number and approval version. Names uniformly fit the supplied box at 3.6 mm target / 2.8 mm minimum ink height, split only at spaces. Accent marks are included in measured ink bounds. Unsupported glyphs or overflow return `NEEDS_LAYOUT` with the full source intact. No rookie claim is inferred. The additional whole/half numerals use an explicit pinned Roboto Condensed numeral recipe inside the original 9.47 × 10.2 mm grade frame; numeral proportions are independent of the uniformly scaled name rule.

The approved default `full-cert-arc-v1` replaces the sample short certificate with the complete existing `ATLAS-0123456789AB · V1` on the original 6.78 mm baseline radius. The fixed 120° maximum span gives this example 0.930226 mm ink height and the widest twelve-hex-character version-one certificate 0.856546 mm, with a 0.85 mm minimum; longer content gets layout attention. The recipe includes these bounds in its profile hash. It preserves the decorative waveform and leaves at least 0.25 mm between the tested certificate and original grade frame. The explicitly named `full-cert-under-name-v1` comparison replaces that waveform with a 1.1 mm certificate and is not the default. Neither option shortens certificate identity. Both use the unchanged cut geometry.

PRINT contains black/gray ink, white metadata and transparent foil/cut openings. PREVIEW_ONLY adds a separately generated gold/holographic substrate simulation through the same body clip. Material is configuration, never selected by grade. The print validator refuses preview art, fonts/text nodes, external resources and embedded images.

Individual PNGs are 6458 × 1898 at nominal 2400 ppi and retain the complete 68.342 × 20.082 mm canvas. Diagnostic sheets are 9764 × 12598 at nominal 800 ppi on the complete 310 × 400 mm canvas. Effective X/Y ppi and pHYs account for rounding. Binary alpha uses the fixed threshold 128, with transparent RGB zeroed. A serialized child process rasterizes vector strips directly at output scale and streams deterministic PNG chunks. It never builds a full-plate RGBA buffer. Its bounded queue, child timeout, strip size, byte bounds and native versions are explicit; the grading event loop does not perform rasterization.

Local Mac software proof of the final 120° recipe: a full 50-label sheet completed in 51.373 seconds at 349,437,952 bytes peak sampled child RSS; the sports individual completed in 1.426 seconds at 312,655,872 bytes. Independent streamed decoding checked every alpha byte in the full sheet and 100 ink/NFC probes across all 50 slots. This is not target-host capacity qualification. Tests verify repeated PNG byte hashes, binary alpha, physical holes, vector cut clearance, full certificates, all 19 allowed grades, canonical CAD hashes, all 50 transforms, partial-sheet margins and import mapping. Original SVG/PNG test specimens remain independently available in the supplied package.

The nominal jig lives in `../jigs/atlas-label-jig-v1.json`; its browser-safe projection is `src/label-sheet-geometry.mjs`. Integer micrometres are the positional authority. CAD DXF bytes are retained unchanged. Aperture clearance, kerf, support height, actual blank thickness, installed eufyMake transparent-margin behavior, machine anchor/origin, physical registration and ink quality remain unqualified. Export manifests expose null X/Y and calibration hash until an explicit top-left calibration profile exists; software rendering is not physical print completion.
