# ATLAS independent research

The staff research action uses the current approved report identity and the original photo lineage already bound to that approval. `research-photos.mjs` reads verified decoded frames and creates bounded JPEG research derivatives; neither grading originals nor approved report artifacts are changed. The v6 shared core performs sold-listing/photo/variation research. Results return the existing market-compatible preview plus private research annotations. Deliberate selection uses the unchanged market-selection endpoint and appends optional report presentation.

The `research_effect` journal belongs to the existing `presentation_market` intent. The original single STARTED/READY/UNKNOWN reservation cannot represent several independently dispatched sources/images/model calls, raw replies, usage, or late acknowledgements. Existing immutable artifact storage retains the bytes but cannot itself authorize an ordered dispatch or bind a late response to the admitted actor/report/request. This narrowly scoped journal supplies that missing authority; it introduces no catalog schema or inventory authority.

Research reservation and INIT share one transaction using the server-owned `reserveMarket` callback. The journal binds current reviewer/card/actor/report scope and a policy hash. Each exact effect envelope is stored before a contiguous DISPATCH. Its exact response bytes/hash and numeric usage are stored before response acknowledgement and result adoption. Receipts are append-only. A restricted SQL function may acknowledge only an already admitted exact DISPATCH after caller disconnect, session expiry, or superseded approval. It cannot dispatch work. Re-entry reads acknowledged effects; an unknown SOURCE/MODEL/image outcome never buys that effect again. A running request can outlive the caller's HTTP response; the same request observes PENDING and later its saved result. Process death after dispatch remains honestly unknown unless actual response evidence was retained.

Research uses the shared pure research core with direct SoldComps/OpenAI effects and ATLAS-owned durable evidence. It has no Ten Kings catalog discovery, lookup, media, proposal, or photo-contribution connection. Staff research returns identity, source/photo comparisons, and sales evidence; it does not publish catalog knowledge. Retired contribution controls and routes are absent.

Configuration requires enabled presentation/market, `ATLAS_MANUAL_RESEARCH_ENABLED`, existing `ATLAS_MANUAL_OPENAI_KEY` and `ATLAS_MANUAL_SOLD_COMPS_API_KEY`. Construction makes no network calls. Retired catalog environment variables have no runtime effect. The independent research, effect, and variant policy versions prevent new requests from reusing the previous catalog-coupled contract. The separate reviewed defect-learning pipeline is unchanged.

`researchGrantSQL` grants only SELECT/INSERT on the research journal and execution of its restricted receipt function. It adds no cross-application database grants. `scripts/validate-research-postgres.mjs` applies the current standalone ATLAS baseline and exercises the authenticated workflow in owned disposable PostgreSQL with synthetic provider responses; `ATLAS_RESEARCH_EVIDENCE` must name a new absolute owned output directory. No historical Ten Kings migration replay, real provider calls, human approvals, catalog publications, hardware actions, or live completion are claimed by those fixtures.
