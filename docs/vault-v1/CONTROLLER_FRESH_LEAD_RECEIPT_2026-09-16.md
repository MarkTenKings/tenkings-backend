Composition: validate config → `WaveshareCommandJournal(path, waveshareBindingDigest(config))` → `LinuxWaveshareSerialTransport(options)` → `WaveshareControllerAdapter(config, transport, journal)` → `initializeReadOnly()`. Shared `adapter-runtime.ts`, CLI, contracts and machine guards were integrated by root. The adapter is `OFFICIAL_TEST` only. Config requires observed serial identity, explicit address/firmware per endpoint, exact mapping/version/profile digest, `pulseMs:100`, settle/gap settings and a reviewed `qualificationEvidenceDigest`. Null qualification permits startup reads but keeps output readiness false. A fabricated digest is not qualification.

Before every pulse, all configured boards' identity and all output bits—including unmapped channels—must match and report OFF. The journal durably records the attempt and halt before dispatch. The queue retains ownership through the hardware timer, settle, all-board OFF readback and minimum OFF interval. It never infers an opened door from an ACK. Missing ACK/readback, malformed replies, ON state, storage failure or helper death prevent further output. Post-write uncertainty remains `SENT_UNKNOWN/UNCERTAIN`; startup cannot clear it. An idle helper exit invalidates readiness and durably halts at the next identity probe.

`recoverReadOnly(evidenceSha256)` restarts the helper and verifies identity/OFF before recording an explicit recovery. It does not retry an output, send cleanup OFF, change historical unknown receipts or resolve the machine's separate sale/recovery state. Callers must enforce staff authority. Replaying a historical unknown command relatches the adapter.

Preserve the controller sidecar together with the main database. Configuration binding includes the qualification digest: creating an unqualified service journal and subsequently changing that digest rejects reopening. Complete initial qualification with the standalone bench before service-ledger creation, or arrange an explicit reviewed transition. Never delete/replace a ledger to bypass the check.
