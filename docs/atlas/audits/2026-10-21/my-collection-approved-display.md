The saved public packet's exact serialized SHA-256, strict `atlas-public-manual-report-v2` shape, mode, certificate, token and version are checked before using identity or the recorded final grade. The existing pure public contract also binds each image to the saved inspected image hash. `reportHash` identifies the private approval and is preserved within the verified public packet; it is **not** recomputed from the redacted public report. No grading runtime or score calculation is invoked.

The actual public contract admits 1350×1858 WebP inspection photographs. These are approved grading derivatives, **not raw intake masters or calibrated slab photographs**. The new display uses exact saved Front bytes, no label ACL, crop, generated replacement, transform or public/provider URL fallback. Metadata is capped at 16 KiB, internal packet input at 8 MiB and photo delivery at 2 MiB. Larger valid saved photos retain title/grade with an explicit size-limit state. Container/header dimensions, MIME, size and SHA-256 are checked before a Blob URL; the actual mounted image must then decode at the expected dimensions before being shown.
