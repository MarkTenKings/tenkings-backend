## Explicit service interfaces

- `previewListingFee(actor,{cardId,askingPriceCents,listingId?})`; POST `/listings/preview`. Publish/revise use the retained `feeQuoteId` when scheduled pricing is configured.
- `quote(actor,{listingId,destinationId})`; POST `/quote`. Old destination-free GET supports legacy fixed fixtures/contracts; a configured destination-required composer refuses it.
- `quoteWithdrawal(actor,{amountCents,externalAccountId,method:'instant'})`; POST `/withdrawals/quote`. Withdraw adds method/quoteId. `/withdrawals/cancel` and `/withdrawals/reconcile` bind the original seller-owned intent.
- `reviewFinanceIncident(actor,{requestId,alertId,expectedVersion,action,reviewRef,evidenceHash})`; POST `/staff/incidents`. Nonlocal independent evidence validation is mandatory.
- `settleInstantFees(actor,{settlementId,intentIds,evidenceRef,reviewRef})`; POST `/staff/instant-fees/settle`. A qualified server reader supplies actual bill evidence/approval; browser cannot post arbitrary provider transactions.
- `retainProviderWebhook({rawBody,signature})` is server-only, independently scoped and explicitly enabled by webhook ingress configuration. Hosted finance chooses retention only when its matching ingress worker is configured.
- `createR1MarketplaceRouteComposition({enabled:false,host,finance?,maxConcurrent?})` exposes `wrap(surface,existingHandler)`, explicit `startFinance/stopFinance`, status and close/drain. No automatic job starts or credential discovery.
