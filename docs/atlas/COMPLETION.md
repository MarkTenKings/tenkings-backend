# ATLAS completion and acceptance

Owner clarification recorded September 7 Pacific / September 8 UTC, 2026. The canonical V2 blueprint contains the approved ATLAS amendment. This checklist describes the actual intended staff system; a synthetic preview is an intermediate milestone.

## The finished workflow

1. Approved staff sign in with a phone code and receive a separate, revocable ATLAS session.
2. Staff intake a physical card and its Front/Back photos. Preserve original bytes, preparation attempts, measurements and all raw findings.
3. The existing ATLAS grading system performs deterministic preparation, measurements, detection and grading. Astra operates the bounded workflow and proposes identity/finding corrections through scoped tools. It cannot certify, publish, approve learning or perform commercial actions.
4. Human reviewers receive a queue of completed ATLAS reports. Each reviewer can inspect the actual evidence, correct the draft, save and approve the exact final revision. Corrections retain all earlier findings and decisions, and trigger deterministic recalculation/rendering.
5. Approval makes the approved ATLAS report public and marks grading complete. Subsequent changes require a new review/approval; public output must not quietly display an unapproved draft. Stable report links and prior approved versions are retained.
6. The finishing workspace prepares the exact label and NFC job for that card/report. The supported existing code targets the Dell Windows workstation, ACS ACR1552U, FEIJU F8215 and GoToTags Desktop 4.37.0.1. A human performs the current Start Encoding action and physical tag placement. Only verified exact-URL readback and permanent-lock evidence from an approved helper can mark NFC verification complete.
7. Staff print the label and assemble label, NFC tag, card and slab, then sonic-weld it. Record the human finishing confirmation separately from software grading/NFC facts; software cannot independently observe assembly or welding.
8. Complete a fixed ten-card supervised batch. Review actual outputs and failures, measured costs and elapsed time. Expansion follows accepted results.
