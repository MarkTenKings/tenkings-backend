## Authority and work

Fresh human operations admission names one exact uninitialized specimen in the fixed ten-card pilot. Separate admission and execution HMAC purposes/keys prevent the runner from creating permission. The private execution service independently validates the current human scope, preserved source/preparation and current map/Memory/worker policy, performs original INITIALIZE with fresh detection, and commits exactly one matching operator run. The runner preserves the admitted initialization ID after a lost reply and only uses the service's durable same-job replay. Failed/unknown initialization or a missing confirmed run never constructs the provider.

Implemented adapters read the exact report, verify original images and render bounded native crops/overviews, record identity/finding proposals and submit the current report to the human queue. The decoder remains locked Sharp 0.33.5/libvips 8.15.3; animation, substituted bytes, incorrect geometry/dimensions and unsupported containers are rejected. Explicit EXIF coordinates and source/transform hashes preserve evidence lineage. Recorded image delivery establishes delivery, not model inspection quality.

The model cannot supply a credential, role, provider URL, SQL, shell, report grade, invoice charge or physical fact. Certification/publication, trusted-learning decisions, operational authority and invoice settlement remain human boundaries. Optional catalog/comps tools are not advertised without an implemented admitted adapter. Human proposal decisions and deterministic corrections remain separate actions; identity changes requiring new map/category/layout authority return an advisory and do not start processing.

## Provider and ledger

The fixed Responses transport uses exact `gpt-6-astra`, pinned supported effort/instructions/tool schemas, `store:false`, one tool at a time, bounded output and disabled truncation. All output items, including opaque encrypted reasoning, are retained for stateless continuation and matched by call ID; opaque content is never interpreted as an explanation. Dedicated ATLAS project/key, fixed endpoint, no redirects and no automatic retries remain required. Official API/pricing facts were checked during the September 8 implementation; revalidate the pinned provider policy before a paid release.

Immutable run/attempt/receipt/step/outbox records bind runtime/policy/evidence and analysis/review heads. Restricted runner grants are checked on every transaction. Fenced leases, one-time dispatch, deadline/action/request limits and shared worker/model reservations prevent accidental concurrent or repeated paid work. Unknown outcomes retain exposure. Provider usage ceilings and actual invoices are distinct evidence; absent usage is never zero cost. The implementation's conservative reservation policy is a cap, not an expected card price or permission to spend.

Each tool result, next continuation/revision and outbox event commits atomically. Receipts may be retained after expiry/revocation without granting further dispatch. Human work is interlocked with unresolved machine work. Explicit operations recovery may cancel never-dispatched jobs or abandon uncertain work while retaining receipts, actual charges and holds; it cannot requeue the same uncertain evidence silently. Late actual worker instrumentation remains part of provider/worker operational acceptance.

## Packaged launch

[README.runtime.md](../../packages/atlas-operator/README.runtime.md) defines the exact offline producer and one-shot launcher. Exactly one admitted run ID or initialization ID is selected. An independently retained manifest hash binds the full read-only file inventory, actual Node executable/version/architecture, generated Prisma 5.22 client/schema and one native engine, closed JavaScript/source hashes and optional initialization authority. The producer uses only installed locked dependencies. No mutable development-tree import substitutes for the packaged runtime.

Environment guards reject debug/Node loader, Prisma/engine, native loader, OpenSSL and certificate-file overrides. This does not make a same-owner writable deployment tamper-proof or undo pre-JavaScript initialization. Trusted executable provenance, launcher, operating-system trust base and deployment ownership remain necessary.

The accepted native parser supports thin Darwin arm64 Mach-O with protected macOS system libraries. Two synthetic inactive Node 22.23.2 artifacts reproduce and include M13. Linux/Docker needs a selected architecture/libc/OpenSSL baseline, exact Linux Node/Prisma engine and reviewed ELF closure checker; a Darwin artifact is not Linux acceptance. No live operator host or credentials were chosen.

SIGINT/SIGTERM abort new work, preserve bounded receipt drain and disconnect handling, and emit only a projected result. A timeout does not claim rollback. Exit zero means a retained human-review handoff, never report approval. No provider response, token, private reasoning or raw exception is printed.
